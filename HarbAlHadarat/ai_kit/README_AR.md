# دليل العمل مع qwen2.5-coder:14b

## 1) التجهيز (مرة واحدة)
1. ثبّت Ollama ثم من PowerShell:
   `ollama pull qwen2.5-coder:14b`
2. أنشئ النموذج المضبوط لهذا المشروع (من مجلد المشروع):
   `ollama create godot-coder -f ai_kit/Modelfile`
   (يضبط السياق على 8192 والحرارة 0.2 ويحفظ قواعد Godot 4 كتعليمات دائمة.)
3. ثبّت Python 3 إن لم يكن موجوداً: `winget install Python.Python.3.12`
4. تأكد من git: نفّذ `git init` ثم `git add .` ثم `git commit -m start` في مجلد المشروع.

## 2) الاستخدام اليومي
```
python ai_kit/ask.py "المهمة" scripts/الملف.gd --func اسم_الدالة
```
- الأمر يرسل للنموذج: قواعد المشروع + الدالة المطلوبة فقط + المهمة.
- بعد الرد يفحص الناتج آلياً (صياغة Godot 3 والأقواس والمسافات) ويعرض الفرق.
- لا يغيّر شيئاً إلا إذا أضفت `--apply` (ويحفظ نسخة .bak قبل التعديل).
- المقترحات تُحفظ في `ai_kit/out/`.
- لمعرفة حجم الطلب دون إرسال: أضف `--dry-run`.

أمثلة:
```
python ai_kit/ask.py "make archers keep distance 8 meters instead of 6" scripts/game.gd --func _ai_enemy
python ai_kit/ask.py "add 3 more memory lines in Arabic in the same style" scripts/story.gd
python ai_kit/ask.py "add a new enemy type 'slinger': ranged, hp 2, speed 2.8" scripts/catalog.gd --func _fighter_stats --apply
```
فاحص الأخطاء وحده (مفيد لفحص أي كود ينسخه لك أي نموذج):
`python ai_kit/lint_gd.py scripts/game.gd`

## 3) كيف تكتب المهمة
- **اكتبها بالإنجليزية** وجملة أو جملتان: ماذا تغيّر، وما الذي لا يُمس.
- **مهمة واحدة** في كل طلب. لا تجمع ثلاث ميزات.
- **دالة واحدة** في كل مرة (`--func`). إن احتجت دالتين فاعمل طلبين.
- اذكر القيم بالأرقام: «20% slower»، «range 8 meters».
- لا تطلب «حسّن الكود»؛ اطلب تغييراً قابلاً للتحقق.

## 4) الحلقة الصحيحة
1. `git commit` قبل كل مهمة.
2. شغّل ask.py وراجع الفرق (لا تطبّق ما لا تفهمه).
3. طبّق بـ `--apply`، افتح Godot وجرّب.
4. نجح: `git commit`. فشل: `git checkout scripts/الملف.gd` أو استعد من .bak.
5. إن ظهر خطأ في Godot، انسخ الرسالة كما هي (السطر والنص) وأرسلها في طلب جديد:
   `"Fix this Godot error: <النص>"` مع نفس الدالة.

## 5) السرعة (جهازك بلا بطاقة رسوم)
- أغلق المتصفح والبرامج الثقيلة قبل التشغيل؛ النموذج يحتاج نحو 9 جيجابايت.
- توقع 2 إلى 3 توكن في الثانية: رد من 300 توكن يستغرق دقيقتين إلى ثلاث. ابدأ الطلب واتركه.
- اجعل الطلبات قصيرة. لا ترفع `--ctx` فوق 8192 (يستهلك رام ويبطئ).
- أول طلب بعد فترة أبطأ لأن النموذج يُحمَّل. لإبقائه محمّلاً: `setx OLLAMA_KEEP_ALIVE 30m` ثم أعد تشغيل Ollama.

## 6) ما يناسب النموذج وما لا يناسبه
يناسبه: تعديل أرقام وسلوك داخل دالة، إضافة سطور حوار، إضافة نوع عدو بنفس النمط، شرح دالة، كتابة تعليقات.
لا يناسبه: ميزة جديدة تمس عدة ملفات، إصلاح خطأ لا تعرف سببه، تغيير نظام الحركة أو الأنيميشن.
هذه الأعمال الكبيرة أرسلها لي في المحادثة مع رسالة الخطأ أو وصف ما يحدث.

## 7) إن أعطاك النموذج نتيجة سيئة
- الفاحص يشير إلى صياغة Godot 3: أعد الطلب وأضف في آخره: `Use Godot 4 syntax only. Previous output had: <رسالة الفاحص>`.
- أعاد الملف كله بدل الدالة: أضف `Return only the function`.
- بدأ يخترع دوال غير موجودة: أعطه الدالة التي يحتاجها مع `--func` أو انسخ توقيعها في المهمة.
- بعد محاولتين فاشلتين، لا تكرر. صغّر المهمة أو أرسلها لي.
